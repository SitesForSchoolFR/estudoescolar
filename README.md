# 📚 Estudo Escolar

Portal de **estudos escolares** com quizzes interativos, resumos por matéria, atividades de matemática, português, história, biologia, física, química e geografia — além de jogos educativos para os intervalos e o recreio.

## ✨ Recursos
- Quizzes e atividades interativas por matéria (modo pânico com questões reais de prova, tecla configurável)
- Mais de 1.300 atividades e jogos educativos organizados em coleções (Famosos, Favoritos, Joias Escondidas, Ports, Retrô, Ritmo e muito mais)
- Perfil do estudante com XP, níveis, streak diário, conquistas e ranking global
- Chat global da turma em tempo real, com canais de dicas e recordes
- Personalização completa: temas (inclui tema claro "Caderno"), backgrounds interativos animados, cursor customizado, camuflagem da aba e modo discreto
- Tudo abre em janelas limpas `about:blank`, sem instalar nada

## 🛠️ Tecnologias
HTML, CSS e JavaScript puro (sem build), hospedado no GitHub Pages. Chat e ranking globais via protocolo Nostr (assinaturas Schnorr BIP-340 implementadas do zero), com cache local e sincronização entre abas.

## ⚖️ Créditos
Catálogos e mirrors: DuckMath, GN-Math, GN-Math v2, P2P (WebSight) e Ported2Browser. Todos os jogos pertencem aos seus desenvolvedores e estúdios originais — apoie os criadores adquirindo as versões oficiais.
